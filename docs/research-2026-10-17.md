# بحث أدوات الفيديو — 2026-10-17

مصدره: جلسة مشروع sudegy-sales. الأرقام (النجوم والرخص) كما ظهرت في صفحات GitHub وقت الجلب، ولم يُتحقق منها بشكل مستقل.

## الخلاصة
ما وجدنا أداة وحدة تسوي كل شي. الأقرب ثلاث طبقات مع بعض: تركيب الفيديو بالكود، ثم ناقد يشاهد الناتج، ثم إصلاح وإعادة رندر. كل الأدوات تعمل كـ skills داخل Claude Code.

الجهاز لا يشغّل نماذج توليد الفيديو المحلية: GeForce 930MX بذاكرة 2GB، الرام 7.8GB. المسار الواقعي هو فيديو مبني بالكود فوق لقطات شاشة حقيقية للمنتج، وهذا يناسب قاعدة AGENTS.md: ديمو 15 ثانية على الجوال. Node وffmpeg وgit موجودة، و gh وyt-dlp غير مثبتين.

## الأدوات

| الأداة | وش تسوي | النقد والإصلاح | ملاحظة |
|---|---|---|---|
| HyperFrames (HeyGen) | تكتب HTML وتطلع MP4، لها skill لـ Claude Code. Apache-2.0، بدون رسوم رندر | أوامر lint وcheck وsnapshot وpreview وrender | الأساس المقترح للرندر |
| motion-video-kit | إعلانات تجارية لأعمال حقيقية. MIT | حلقة نقد "Gauntlet": الحاكم غير الباني، نقّاد على الرندر الفعلي، قياس loudness وإطارات متجمدة وتباين | غير واضح هل الإصلاح تلقائي ولا هل يدعم 9:16 |
| claude-remotion-skill | يعلّم Claude صنع motion graphics بـ Remotion. MIT | حلقة إلزامية: رندر، فحص إطارات بـ ffmpeg، إصلاح، إعادة رندر | معايير الفحص غير موثقة |
| OpenMontage | نظام إنتاج كامل بـ 11 pipeline (الصفحة تقول 12) | مراجعة ذاتية بعد الرندر (ffprobe وإطارات وصوت) | لا إصلاح تلقائي موثق، لا pipeline إعلانات. AGPLv3: انتبه إذا نقدمه كخدمة |
| ad-video-skills | قالب مع CSV يعطي N نسخة إعلان بمقاسات 9:16 و4:5 و1:1 و16:9. MIT | لا يوجد | مفيد لاختبار الـ hooks. تبعياته غير موضحة |
| watch-video-skill | يخلي Claude "يشاهد" فيديو عبر نص مزامن مع إطارات. MIT | هو طبقة المشاهدة والنقد | الملفات المحلية تكفيها ffmpeg. Whisper API اختياري |

غير موصى به: open-ai-video-agent (8 نجوم فقط، يعتمد على خدمة مدفوعة muapi.ai). قائمة أوسع: awesome-claude-video-skills (~180 مستودع).

## تحفظات
- "فيروسي" لا تضمنه أي أداة. الأدوات تعطي جودة ثابتة ونسخاً كثيرة للاختبار. الانتشار الفعلي يجي من الـ hook والنتيجة المعروضة والتوزيع.
- العربي في الفيديو: HyperFrames وRemotion يرندران عبر Chrome فالنص العربي RTL يفترض يطلع سليماً. هذا استنتاج لم يذكره الـ README، لازم يتختبر.
- الصوت: NAMAA Saudi TTS (MIT، سعودي). كل ما قُرئ عنه ادعاءات البائع بدون مقارنة مستقلة. يلزم اختبار سماعي مع ناطق أصلي.
- الأمان: هذه الـ skills تنفذ تعليمات وسكربتات على الجهاز. تصنيف "SAFE" جاء من قائمة طرف ثالث، فيُقرأ كود أي skill قبل تثبيته.
