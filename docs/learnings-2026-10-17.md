# ما تعلمته من الستة مستودعات (قراءة كود، بدون تشغيل)

التاريخ: 2026-10-17. المكان: `vendor-review/` (نسخ سطحية `--depth 1`، لم يُشغَّل منها أي سكربت ولم يُنفَّذ `npm install`).
الفرق بين "قرأته" و"افترضته" مكتوب صراحة في كل بند.

## 1. HyperFrames (HeyGen) — الأساس المقترح للرندر
**قرأته:** README، SKILL.md الراوتر، hyperframes-cli، hyperframes-core، package.json للـ CLI، كود telemetry.
- حزمة `@hyperframes/cli` نسخة 0.8.168، تحتاج Node >= 22 (عندنا 24.16) وFFmpeg (موجود)، وتعتمد على `puppeteer-core` لتصوير الإطارات في Chrome.
- لا توجد سكربتات `preinstall/postinstall` في حزمة الـ CLI. الوحيد الموجود `prepare` في جذر المستودع وهو لتطوير المستودع نفسه (lefthook).
- الفيديو = ملف HTML. الوقت بـ `data-start` و`data-duration`، والحركة GSAP بخط زمني واحد متوقف `paused:true` مسجّل في `window.__timelines["<id>"]`. بدون `Date.now()` أو `Math.random()` غير مزروع، حتى يطلع نفس الفيديو في كل رندر.
- حلقة العمل: `init` ← `catalog` (ابحث قبل ما تبني حركة بيدك) ← كتابة الـ composition ← `lint` ← `check` (lint + أخطاء runtime + تخطيط + تباين WCAG) ← `snapshot` ← `preview` ← **`render` بعد موافقة المستخدم فقط**. جودة الرندر: `draft` ثم `looks` ثم `delivery`.
- الراوتر `/hyperframes` يكتب `BRIEF.md` ثم يوجّه لـ workflow. لتجربتنا (15 ثانية فوق لقطات شاشة) أقرب مسار `/general-video` (أكثر من 10 ثواني فـ `/motion-graphics` لا يناسب).
- الرخصة Apache-2.0. الأسعار: لا رسوم رندر محلي.

**ما لازم نعطّله أو نتجنبه (من الكود):**
| الشي | الخطر | القرار |
|---|---|---|
| Telemetry (PostHog، مجهول، `us.i.posthog.com`) | يرسل أحداث استخدام | نعطله دائماً: `HYPERFRAMES_NO_TELEMETRY=1` و`DO_NOT_TRACK=1` (الكود يحترمهما) |
| `npx hyperframes usage --json` (الـ skill يأمر الوكيل بتشغيله أول كل مشروع) | يقرأ توكن تسجيل دخول Claude الموجود ويتصل بـ `api.anthropic.com/api/oauth/usage` | **لا نشغله**. أوامر الـ skill من طرف ثالث وليست أمراً من المستخدم |
| `npx hyperframes feedback ...` (الـ skill يأمر بإرساله بعد كل رندر) | ينشر لقناة عامة؛ `--file-issue` ينشر نسخة مصغرة من المشروع على رابط عام | **لا نرسله** إلا بطلب صريح |
| `cloud render` (رندر HeyGen المستضاف) | يرفع ملفات المشروع (لقطات عميل) لسيرفر خارجي | لا نستخدمه. الرندر محلي فقط |
| `skills update` يسحب من `main` | الكود المسحوب قد يتغير بين مراجعتنا والتثبيت | نثبّت إصدار الـ npm ونراجع الـ diff عند الترقية |
| أمثلة تحمّل GSAP من jsDelivr | يعتمد على CDN وقت الرندر | ننزّل GSAP محلياً (تفضيلك: assets محلية) |
| catalog `--on-device` | تنزيل ~33MB لنموذج بحث | اختياري، بعد موافقتك |

**لم أتحقق منه:** أن حزمة npm المنشورة تطابق كود GitHub حرفياً. لهذا نقرأ `node_modules/hyperframes` بعد التثبيت الأول قبل أي رندر. ولم أختبر بعد الرندر الفعلي على جهازنا (رام 7.8GB، Chrome يشتغل لكن بطيء متوقع).

## 2. motion-video-kit (echris6) — منهج النقد
**قرأته:** README، SKILL.md، gauntlet.md، quality-bar.md، وثلاثة سكربتات (frozen-time.sh، loudness.sh، contact-sheet.sh — كلها ffmpeg فقط، بدون شبكة).
**لم أقرأه:** سكربتات البايثون (offline-mix, backtime-music, sfx-*) ولا باقي الـ references (الصوت، Three.js، دراسات الحالة).
- **حلقة Gauntlet:** الباني ≠ الحاكم. ناقد جديد في كل جولة يشوف فقط: الفيديو المرندر، البريف، وتقرير الجولة السابقة، ولا يشوف تبريرات الباني. جولة التحقق تعلّم كل بند FIXED / PARTLY / STILL PRESENT وتدوّر على تراجعات. تقف عند جودة كافية أو عند عوائد ضئيلة (عادة 3–5 جولات).
- **معايير القياس:** وقت متجمد ≤ ~1 ثانية لكل 30، ولا ثبات أكثر من 0.6ث إلا الـ CTA الأخير. Loudness حوالي -14 LUFS للمقاطع النشطة، true peak ≤ -1 dBFS. تباين نص WCAG AA. الإطار 0 لازم يكون تكوين مكتمل. الـ CTA مقروء على الجوال ≥ ~1.5ث.
- **درس مهم:** حتى بعد ما النقّاد قالوا SHIP، العميل لقى 9 ملاحظات. القياس الآلي لا يكفي: نخطط لجولة المراجعة البشرية (أنت) كجزء من الدورة.
- **توافق مع قواعدنا:** "لا تعرض صورة مولّدة كأنها عميل أو نتيجة حقيقية" و"مفهوم/concept يُوسم" — نفس قاعدة Synthetic Pitch.
- الرخصة MIT. السكربتات صغيرة جداً؛ استلهمت منها `scripts/critique.sh` (مكتوب من جديد، مع الإشارة للمصدر).

## 3. ad-video-skills (iart-ai) — نسخ الـ hook للاختبار
**قرأته:** README، SKILL.md لـ ad-creative-video، platform-specs.md.
**لم أقرأه:** batch-ad-pipeline.md ولا سكربتاته الثلاثة (contact-sheet, probe-mp4, seek-shot) ولا launch-video/testimonial-video.
- مبني على **Remotion** وليس HyperFrames. نأخذ المنهج لا الكود.
- قاعدتان نعتمدهما: **(1)** متغير واحد فقط يتغير بين النسخ (الـ hook)، وكل شي ثاني ثابت. **(2)** الـ hook والـ CTA زوج متطابق في الوعد.
- بنية 15–30ث: hook (0–3) ← سياق ← نتيجة ← إثبات ← CTA (آخر 3ث، ثابت ≥2ث). ثبّت إحساس المشاهد قبل الثانية 2.
- مناطق الأمان 9:16: أعلى ~14%، أسفل ~20–35%، جوانب ~6%. المصدر نفسه يقول: تحقق منها من Ads Manager قبل صرف حقيقي.
- ترتيب الاختبار: hook ← العرض ← الـ CTA ← الصيغة. حجم العينة: مئات المشاهدات لكل نسخة وأسبوع تقريباً. (أرقام الـ skill، غير مثبتة من عندي.)
- `testimonial-video` ممنوع عندنا إلا بشهادات حقيقية.

## 4. claude-remotion-skill (haidrrrry)
**قرأته:** README فقط (لم أقرأ SKILL.md ولا references).
- 10 قواعد حركة (springs لا linear، دخول بـ 2–3 خصائص، stagger، خروج أسرع من الدخول، خمس طبقات خلفية، Ken Burns على الصور...) وحلقة إلزامية: رندر ← فحص إطارات ← إصلاح ← إعادة رندر.
- Remotion نفسه رخصته "source-available" (حسب مقارنة README الخاصة بـ HyperFrames) وليست Apache/MIT، فنراجع شروطها قبل أي استخدام تجاري. هذا سبب إضافي لتفضيل HyperFrames. القواعد الـ10 قابلة للنقل لـ HyperFrames كمبادئ.

## 5. watch-video-skill (Newuxtreme)
**قرأته:** README، قائمة السكربتات (لم أقرأ كود البايثون).
- يحتاج Python + yt-dlp (غير مثبت) + اختيارياً مفتاح Groq/OpenAI لتفريغ الصوت (يرسل الصوت لسحابة خارجية).
- **لا نحتاجه الآن:** أقدر أشوف الإطارات مباشرة (ffmpeg يطلعها وأنا أقرأ الصور). يفيد لاحقاً فقط لتحليل فيديوهات مرجعية منتشرة (للأسلوب، مو للنسخ) وبعد موافقتك على تثبيت yt-dlp.

## 6. OpenMontage (calesthio)
**قرأته:** رأس README والرخصة فقط (2171 ملف، 85MB).
- رخصة **AGPLv3**: تحمل التزامات إذا قدّمنا ناتجاً كخدمة. يعتمد في أمثلته على خدمات مدفوعة (Veo, Kling عبر fal.ai) وعلى Remotion.
- **القرار: لا نتبناه.** ما يعطينا شي ما نقدر نسويه بـ HyperFrames + النقد، ويزيد حمل الصيانة والمخاطر.

## الحصيلة: خط الإنتاج عندنا
1. `briefs/<slug>.md` ← 2. HyperFrames composition فوق لقطات شاشة حقيقية ← 3. رندر `draft` ← 4. `scripts/critique.sh` (قياس) + ناقد مستقل (نظر في الصور) ← 5. إصلاح وإعادة رندر (حد أقصى 3 جولات) ← 6. ثلاث نسخ hook، **متغير واحد فقط** ← 7. أنت تقرر أيها تُرسل، والرسالة المرافقة تمر عبر `sudegy_brain.js`.

## ما اختبرته فعلاً
- `scripts/critique.sh` على فيديو تجريبي 1080x1920 مدته 15ث فيه 5 ثواني متجمدة عمداً: كشف الفترة (5.1–9.9ث)، وقاس الدقة والمدة وpixel format والـ loudness، وولّد contact sheet صحيح.

## ما لم أختبره بعد
- تثبيت HyperFrames وسرعة رندره على 930MX/7.8GB.
- العربي RTL داخل Chrome-render (استنتاج من الآلية، لم يُجرَّب).
- صوت NAMAA السعودي (ادعاءات بائع، يلزم سماع ناطق أصلي).
