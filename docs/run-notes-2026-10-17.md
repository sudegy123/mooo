# ما اكتشفناه بالتشغيل الفعلي (2026-10-17)

مكمّل لـ `learnings-2026-10-17.md` (ذاك من قراءة الكود، هذا مما حدث فعلاً على الجهاز).

## الجهاز
- **القرص C: شبه ممتلئ** (30–90MB فاضية؛ npm-cache وحده ~5.8GB). كل شي جديد على G:. الغلاف `scripts/hf.ps1` يوجّه التيمب وكاش npm وكاش الإطارات إلى `G:\sudegy-video-studio\.cache`. `.npmrc` المشروع يوجّه كاش npm لـ G: أيضاً.
- **لا تحوّل USERPROFILE/HOME** لتشغيل HyperFrames: Chrome يرفض يبدأ ("browser is already running") لما يكون Chrome المستخدم مفتوحاً. جربته وفشل، فأزلته.
- **WebGL:** مع Edge/Chrome بدون أي أعلام يستخدم كرت Intel HD 620 عبر D3D11. أعلام SwiftShader (برمجي) خلّت صفحة العرض أبطأ ~50 مرة (13 دقيقة وفشل مقابل 32 ثانية).
- **سرعة الرندر:** 15 ثانية 1080x1920 بجودة draft = 1 دقيقة و33 ثانية (عامل واحد، التقاط screenshot، GPU حقيقي). الرام المتاحة ~0.9GB فقط، فعامل واحد دائماً (`--workers 1`).
- HyperFrames افتراضياً يحاول تنزيل `chrome-headless-shell` على C: ويفشل بـ ENOSPC. الحل: `HYPERFRAMES_BROWSER_PATH` = Chrome المثبّت (`%LOCALAPPDATA%\Google\Chrome\Application\chrome.exe`، النسخة 155). يعمل كطريق screenshot.

## آثار جانبية في HyperFrames (حصلت فعلاً)
| الأمر | وش صار | التعامل |
|---|---|---|
| `snapshot` | إذا `GEMINI_API_KEY` موجود في البيئة يرسل الإطارات تلقائياً إلى Gemini للوصف، ويثبّت `@google/genai` (30MB) في `~/.cache/hyperframes/optional` وقت التشغيل | الغلاف يشيل المفتاح من بيئة الأمر. حذفت الحزمة. إن احتجنا الوصف: `--describe` بقرار صريح |
| أي أمر | محاولات تحديث تلقائي (4 مرات، كلها `skip: Unknown install layout`) وإعداد `telemetryEnabled: true` محفوظ | `hyperframes telemetry disable` (مثبّت في الإعداد) + متغيرات البيئة |
| `render` | يطلب تنزيل متصفح | انظر أعلاه |
| `init` | يفحص skills على GitHub | `HYPERFRAMES_SKIP_SKILLS=1` |

## Nano Banana (توليد الصور)
المستخدم سمح باستخدامه. جربت `gemini-nano-banana-2.1` و`gemini-3.1-flash-lite-image` و`gemini-3.1-flash-image` و`gemini-3-pro-image` بالمفتاح الموجود في إعداد sudegy-sales: **الأربعة ترجع 429 "limit: 0 ... on Free Tier"**. يعني توليد الصور محجوب حتى ترقية الفوترة في Google AI Studio. السكربت `scripts/nanobanana.mjs` جاهز ويعمل أول ما يتغير ذلك (الموديل يقبل `image/jpeg` فقط). لم أبحث عن مفاتيح أخرى.
لذلك الفيديو الحالي بلا صور مولّدة: الخلفيات تصميم بالكود، والمحتوى الحقيقي لقطات شاشة.

## ما بُني
- `scripts/capture_demo.mjs`: يسجّل عرض الأسنان الحقيقي (https://sudegydental.pages.dev/diagnose.html) كجوال بالعربي. لا يضغط زر إرسال واتساب.
- `scripts/build_reel.mjs`: يقص التسجيل لـ 7.35 ثانية مع تسريع الأجزاء الروتينية ويحوّل أوقات الضغطات.
- `scripts/brain_copy.cjs`: كل نصوص الفيديو من `sudegy_brain.js` (GULF_BRAIN) عبر `gemini.js` مع بوابة `checkFirstMessage`. أول محاولة الـ brain اجتازت البوابة لكنها كانت ضعيفة (CTA "شاهد كيف…" بعد العرض)، فأعدنا التوليد بتوجيه أدق 3 مرات. بوابتي عندي كانت فيها ثغرة (التعليقات ككائنات) وأُصلحت.
- `scripts/make_rows.cjs`: يبني 3 صفوف hook من نتائج الـ brain. اختيار واحد بشري موثّق: جملة الألم من المحاولة 3 لأن المحاولة 4 قالت "معظم…" وهذا إحصاء غير مثبت.
- `compositions/dental-triage-15s/`: الفيديو نفسه (HTML + GSAP محلي + خط Cairo محلي).

## الجولة الثانية: "سريع ما أقدر أقرا" + أدوات إضافية
### البحث في GitHub عن أدوات (النتيجة)
بحثت عن: صوت سعودي مفتوح المصدر، أصوات عربية خفيفة (Piper)، أداة OCR عربي للتحقق من الإطارات.
- **NAMAA Saudi TTS**: لم أجد له مستودع GitHub ولا صفحة HF، فقط صفحات تسويقية على tts.ai. حسب وصفها هو تعديل على ChatterboxMultilingual (PyTorch ثقيل) فلا يصلح لجهاز رامه المتاحة < 1GB، ورخصة MIT المذكورة من طرف ثالث غير مؤكدة. **لم أنزّله.**
- **Piper** (صوت Kareem): خفيف على المعالج لكنه فصحى فقط، ومستودعه الأصلي أُرشف وبديله بترخيص GPL. **لم أنزّله** لأن Gemini TTS غطّى الحاجة.
- **OCR عربي**: لا توجد أداة جاهزة؛ تحقق الحروف العربية بقي بالعين + الناقد المستقل.
- لا أداة GitHub جديدة مثبّتة هذه الجولة؛ وما احتجته عملته بسكربتات داخل المشروع أو بخدمات Gemini على مفتاحك.

### ما أُضيف فعلاً

- Gemini TTS: اللهجة السعودية غير موثقة؛ الموثق الفصحى والمصرية.

## دكتور مازن (app.drmazin.net) — فيديو شرح التطبيق، مجال التجميل
- التطبيق الحقيقي: "محلل البشرة الصيدلاني" (أسود وذهبي، برطمان ثلاثي الأبعاد يفتح بالتمرير، 13 سؤالاً متكيّفاً، تحليل، ثم نموذج بيانات يرسل الطلب للدكتور).
- التسجيل (`capture_mazin.mjs`): دخلت كعميلة تجريبية (امرأة، 29)، تخطّيت صورة الوجه (خصوصية)، وتوقفت عند نموذج البيانات: **لم أرسل أي طلب للدكتور**. الأسئلة تتضمن حملاً ورضاعة وعلاجات سابقة؛ اخترت "لا شيء/لم أجرب".

- الناقد المستقل (Gemini): قبلت وميض الأسئلة وسرعة شاشة التحليل (أبطأت المراحل لشبه الوقت الحقيقي)؛ رفضت اعتراضه على الوسم (منتج عميل حقيقي، الوسم "مثال ببيانات تجريبية") وعلى فجوات الصوت (القياس 0.33–0.6 ث).
