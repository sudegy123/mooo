# مصنع فيديوهات سوديجي

أمر واحد يحوّل ملف طلب إلى فيديوهات جاهزة ومفحوصة:

```
node factory/run.cjs factory/jobs/<اسم-الطلب>.json
```

## ماذا يحدث داخل الأمر
1. **النص**: المخ يكتب السكربت حسب القالب الفيروسي المختار، ثم بوابة الكلمات الممنوعة، ثم مدقق إملائي آلي. يُحفظ في `factory/work/<الطلب>/script.json` لتراجعه وتعدّله قبل التصيير.
2. **الصوت**: تسجيل واحد متصل بالفصحى (Gemini)، وتُختار أسرع سرعة تبقى فيها كل جملة مقروءة.
3. **الجوال**: مقاطع التطبيق الحقيقية تُقص وتُسرَّع لتطابق كل جملة.
4. **التركيب**: المشاهد (شخصيات، جوال، عناوين ضخمة، استطلاع، ذهب سائل، جرة ثلاثية الأبعاد، غوص مجهري، دعوة للتعليق) + كلمات مضيئة مع الصوت + مؤثرات صوتية + الملصق.
5. **الفحص والتصيير** عبر HyperFrames على قرص G.
6. **الإنهاء**: موسيقى خلفية مجانية تنخفض تحت الصوت، مستوى صوت -14 LUFS، ثلاثة مقاسات (9:16 و1:1 و16:9)، ملف ترجمة SRT، صورة غلاف.
7. **بوابة الجودة**: لا يُسلَّم فيديو فشل في الفحص.
8. **التسليم**: `READY_TO_SEND/<العميل>/<الطلب>/` مع `report.md` و`post.txt`.

## خيارات مفيدة
| الخيار | الفائدة |
|---|---|
| `--copy-only` | يكتب السكربت فقط لتراجعه |
| `--no-render --preview` | يركّب الفيديو ويصوّر لقطة من كل مشهد بدون تصيير (سريع) |
| `--variants 3` | ثلاث نسخ بخطّافات مختلفة لاختبار أيها ينجح |
| `--redo-copy` | يعيد كتابة السكربت من جديد |
| `--music none` | بدون موسيقى |

## الملفات
- `factory/formats.json` القوالب الفيروسية (موقف يومي، خرافة ولا حقيقة، تحدي ٥ ثواني، ٣ أخطاء، ألم ثم حل، رد على تعليق، مشهد مُرضٍ، حلقة من سلسلة).
- `factory/clients/*.json` هوية كل عميل: الألوان، الحقائق المسموحة، الكلمات الممنوعة، الملفات الرسمية والتسجيلات.
- `factory/jobs/*.json` الطلبات (مثال كامل: `andoria-pov-01.json`).
- `factory/runtime/stage.js` مكتبة الشخصيات والأدوات والحركات.
- `factory/music/` موسيقى مجانية مولّدة (Lyria عبر مفتاح Gemini المجاني).
- `.claude/skills/sudegy-video-factory/SKILL.md` المهارة التي يستخدمها Claude لتشغيل المصنع.
